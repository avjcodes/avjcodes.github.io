    From the developer

    Why I Built This Demo

    Most bar websites die the same way. The site goes up, the events page says whatever it said at launch, and nobody touches it again because touching it means emailing a developer. So regulars stop checking, and the one place that always knows what is on tonight is a chalkboard.

    This page is built the other way around. The lineup is data, and the site works out tonight, this week, and next month on its own. Old shows drop off by themselves. When a new act gets booked, the owner adds it right on the site, in under a minute. The owner demo link above the drinks list is live if you want to try that yourself.

    There is one more thing the calendar does that nobody sees. Every show on this page is also published as schema.org event data, rebuilt whenever the lineup changes, so search engines can list the bar's nights directly in results and on maps. A show added through the owner editor lands in that feed in the same second it lands on the page. Right now it carries 0 upcoming shows.

    The Brass Pelican is not a real bar; the calendar is the point. Because the venue is invented, this page asks search engines not to index it, so a fictional bar's events never turn up in real results. The engraving, the seal and the wing pattern were made for this sample, and the room photographs were generated for it.
