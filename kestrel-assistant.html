How this works

The retrieval is real and it is running in your browser right now. This page carries 16 short excerpts from Kestrel's (invented) policy documents. When you ask a question, a script scores every excerpt against your words, picks the best match, and shows you that exact text with its source. No server, no network requests, nothing leaves this tab.

The production version I build for clients uses the same retrieval pattern with an LLM API on top: the model writes the reply, but only from passages retrieved out of your real documents, and every answer cites where it came from. That grounding is what stops it from inventing policies you never wrote. If the documents don't cover a question, it says so and hands the customer to a human, exactly like this demo does.
