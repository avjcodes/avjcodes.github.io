The Monday report, before and after.

Every Monday, someone at Ninth Hill retyped a week of order emails into a spreadsheet, which took about three hours and produced two competing versions of the truth by noon. Now a script reads the order inbox at 6:00 a.m., and the dashboard below is ready before the first coffee is poured.

03 / How

What actually happened

No magic in this one, and no model in the loop. It is plumbing, done carefully.

  1. A Python script checks the orders inbox every Monday at 6:00 a.m. and pulls the week's order emails.
  2. Product names get matched against one canonical list, so "COL DARK", "Colombia dk rst", and "Colombia drk roast" all land in the same row of the report.
  3. Dates are parsed into one format, and every line total is recomputed from pounds times list price. Totals typed in an email are treated as a claim, not a fact.
  4. The script writes one clean CSV. This page reads that file and draws every chart you see. One source, one format, no second version of the truth.

The three hours went away because the retyping went away. That is the whole trick.
